Нейросеть на основе U-Net для семантической сегментации изображений.

В папке images располагаются полноцветные изображения 512x512 пикселей каждое c автомобилями разных марок, в папке masks - цветные изображения масок автомобилей. 
Пиксели фона соответствуют белому цвету, а различные части автомобиля – своими отдельными цветами. Названия файлов исходных изображений и масок совпадают.
